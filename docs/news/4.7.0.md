# FactionsUUID 4.7.0

*Released July 26, 2026*


## The Colorful Rent and Dues Update

Recolor default messages, charge faction members dues, and charge factions rent!

### Configurable Colors

A `colors` block at the top of the translations.conf` file defines named colors
that are then used throughout every default translation. Now you can easily restyle all messages in one place.

To use this from existing installs, you could do a mass find/replace of the previous colors to swap them out for the defaults.
Or, you know, the chaotic option of just deleting the whole file to let it regenerate. 
**This is the last planned major update to `translations.conf`.**

* Define colors by name in the `colors` section of `translations.conf`. 
    * Colors can be standard MiniMessage text colors (e.g. `gold`) or hex values (e.g. `#85d2e7`).
    * Define your own custom colors as well.
* Also cleaned up inconsistencies and awkward phrasing across many messages in the file.
    * If you only use the default messages I highly recommend just wiping the file, after backing it up, to regenerate it. 
* The colors used `/f help` are now configurable as well.

### New `translations.conf` translations

To make life easier, I plan to list new translations added in updates so you can more easily find them to modify.

* New sections:
    * `aColorfulMessage`
    * `commands.set.setDues`
    * `commands.dues`

    * `commands.admin.set.rentExempt`
* New entries: `commands.home.invulnerable` and `commands.home.invulnerableNoMore`

### Dues

Faction admins can now charge their members a daily fee, paid from the member's personal balance into the faction bank.

* Enable dues via `duesEnabled` in `main.conf` (enabled by default).
* Faction admins configure amounts with `/f set dues`.
* Members can view their current dues and next collection time with `/f dues`.
    * Faction admins see a list of members who owe unpaid debt or have a history of missed payments.

**Dues failure policies**: choose what happens when a member can't afford their dues:

| Policy    | Action                                                             |
|-----------|--------------------------------------------------------------------|
| `RECORD`  | Log the failure to pay, take no automatic action (default).        |
| `DEBT`    | Carry the unpaid amount forward, to be owed in addition next time. |
| `DEMOTE`  | Move the member down one role (stopping at recruit).               |
| `DISMISS` | Kick the member from the faction.                                  |

### Rent

Factions can now be charged daily rent based on how much land they've claimed.

* Enable rent via `rentEnabled` in `main.conf`.
* The rent amount is determined by a configurable equation (`rentEquation` in `main.conf`).
    * The default equation is `10 * claims`.
    * The `claims` variable represents the faction's current chunk count.
* Members can check their faction's current rent and next collection time with `/f rent`.
    * Faction admins also see a history of missed rent payments.
* Admins can exempt specific factions from rent with `/fa set rentexempt <faction>`.
* Admins can view an overview of factions with outstanding rent debt via `/fa rent`.

**Rent failure policies** — choose what happens when a faction's bank can't pay rent:

| Policy                 | Behavior                                                                                                      |
|------------------------|---------------------------------------------------------------------------------------------------------------|
| `DEBT`                 | Carry unpaid rent forward (default); disband after `rentDisbandAfterConsecutiveMissedDays` consecutive misses |
| `UNCLAIM_UNTIL_AFFORD` | Unclaim chunks (least-inhabited first) until rent is affordable                                               |
| `UNCLAIM_ALL`          | Unclaim all the faction's land                                                                                |
| `DISBAND`              | Disband the faction immediately                                                                               |

I suggest waiting a *while* on an existing server before doing the unclaim-until-afford option because
the plugin tracks inhabited time only when the chunk has been loaded. 

A rent-gathering account can optionally be configured to collect rent payments.

When rent is enabled, claiming and unclaiming land will also show the faction's updated rent amount.

### Home Respawn Invulnerability

Players respawning at their faction home can now be granted a brief window of invulnerability.

* Set `respawnInvulnerabilitySeconds` in `main.conf` to the number of seconds of protection.
* Defaults to `0` seconds (disabled). Invulnerability ends early if the player attacks.

## Other Changes

### Autoleave Now Disabled by Default

* `autoLeaveAfterDaysOfInactivity` now defaults to `0` (disabled). Existing configurations unaffected.

### Bug Fixes

* Fixed case-sensitivity issues in several places.
* Improved warp password handling.
* Economy transfer messages now correctly suppress when the economy is disabled, rather than erroring.

### Developer API

* `ConfigColorResolver` — the `TagResolver` backing the new named color system.
* New dues and rent methods on `Faction`.
* New dues methods on `FPlayer`.
* New cancellable events:
    * `FactionAutoUnclaimEvent` - fired per chunk when rent auto-unclaims land.
    * `FactionAutoUnclaimAllEvent` - fired when all land is unclaimed (currently from rent failure).
